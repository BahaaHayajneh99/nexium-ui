Best Practices

✓ DO
  • Use the predefined elevation levels
  • Avoid arbitrary z-index values
  • Keep elevation levels consistent across components
  • Test layering with multiple overlapping elements
  • Document z-index for complex components
✗ DON'T
  • Use z-index values outside the defined scale
  • Nest stacking contexts unnecessarily
  • Use z-index: 9999 or other extreme values
  • Forget about mobile z-index issues
  • Rely on z-index to fix layout problems

CSS Variables

Use these CSS custom properties for elevation:

--zindex-dropdown 500
--zindex-sticky 600
--zindex-fixed 700
--zindex-backdrop 1000
--zindex-modal 1050
--zindex-notification 1100

Common Mistakes

❌ Using z-index: 9999

This creates unpredictable layering. Use the predefined scale instead.

❌ Nesting multiple stacking contexts

Can cause elements to layer unpredictably. Minimize nesting.

❌ Forgetting about scrollable containers

Position: fixed elements inside scrollable containers behave differently.
