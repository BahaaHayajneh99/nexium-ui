Using PRO Components

A subset of {{ commonService.appName }} components - marked PRO in the sidebar (Design Tools, Enterprise, Advanced Interaction, and more) - are gated behind a one-time-purchase license token. Nothing breaks if you don't have one: a PRO component just renders a locked placeholder instead of its real content until you configure a valid token.

1. Get a license token

Pick a plan on the Get PRO License page - a one-time lifetime license, or a cheaper yearly license that you renew manually once a year. Either way, PayPal checkout hands you back a real, unique token tied to your purchase.

2. Configure it once, at your app's root

Add provideNxLicense() to your bootstrap providers - every PRO component anywhere in your app picks it up automatically, no per-component setup needed:

One license, one project

A token unlocks PRO components for the app you configure it in. It's a per-project license, not a per-developer seat.

Nothing breaks without one

Free components work exactly the same with or without a license. Only the components explicitly marked PRO in the sidebar are affected.

Server-verified, not a local trick

Tokens are checked against a real server-side pool tied to verified payments - there's no client-side algorithm to reverse-engineer a valid one from.
