Design Principles

🎯 Consistency

Use the same radius values throughout your interface to maintain visual cohesion

📐 Hierarchy

Smaller radius values for small components, larger values for prominent containers

🔄 Balance

Not every element needs rounded corners - use them purposefully

🎨 Brand

Adjust radius values to match your brand's personality (modern vs. traditional)

CSS Variables

Use these CSS custom properties to apply border radius consistently:

--radius-sm 2px
--radius-md 4px
--radius-lg 8px
--radius-xl 12px
--radius-full 50%

Best Practices

✓ DO
  • Use predefined radius values for consistency
  • Match radius to component importance and size
  • Test radius values on different screen sizes
  • Use CSS variables for easy theme changes
✗ DON'T
  • Use arbitrary radius values across components
  • Apply extreme radius (> 20px) without purpose
  • Hardcode radius values in component styles
  • Use different radius values for the same component type

Customization

You can easily customize border radius values by overriding CSS variables in your application:

:root {{'{'} --radius-sm: 4px; --radius-md: 8px; --radius-lg: 12px; --radius-xl: 16px; {'}'}
