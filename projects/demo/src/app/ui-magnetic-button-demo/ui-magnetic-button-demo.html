Magnetic Button

A button wrapper whose content subtly translates toward the cursor as it hovers nearby, then springs back to center on mouseleave - the "magnetic" micro-interaction popular on premium landing pages. No animation library involved: just an inline transform: translate(x, y) recomputed on mousemove, with a CSS transition for the spring-back. Move your cursor over the buttons below.
