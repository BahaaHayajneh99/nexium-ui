Spacing Utilities

Every margin, padding and gap prefix below is available for each of the five steps on the spacing scale, as a {prefix}-{step} class - for example .mt-3 or .px-4.

Steps

@for (s of steps; track s.step) {
-{{ s.step }} {{ s.value }}
}

Prefixes

@for (g of groups; track g.prefix) {
.{{ g.prefix }}-* {{ g.property }}
}

Usage

<div class="mt-4 px-3 gap-2">...</div>
