Lesson notes

Overview

This lesson walks through how Angular signals model state as explicit, trackable values instead of relying on zone-based change detection to notice updates on its own.

Key concepts

A signal wraps a value and notifies its consumers when it changes; computed() derives new state reactively, and effect() reruns a side effect whenever the signals it reads update.

Common mistakes

A frequent pitfall is reading mySignal instead of mySignal() - the former is just the accessor function, not its current value, so templates and comparisons silently stop updating.

Further reading

Check the official Angular signals guide for migration tips, and the RxJS interop package if you need to bridge signals with existing observable-based code.
