Component-Specific Patterns

nx-command-palette and nx-mention implement full arrow-key + Enter/Escape navigation over their filtered list, per the WAI-ARIA Authoring Practices patterns. Every other interactive element - including composite widgets like nx-menu, nx-tabs and nx-datepicker's calendar grid - is reachable via Tab today, but doesn't yet implement roving arrow-key navigation within the widget itself. That's a real, tracked gap rather than a documented feature - see the Testing page for how to audit it.
