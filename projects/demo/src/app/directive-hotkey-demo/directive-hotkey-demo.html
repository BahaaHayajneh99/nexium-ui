Hotkey

Binds a key combo spec like 'ctrl+k', 'ctrl+shift+p', 'escape' or '/' to a document-wide keydown listener, and emits (nxHotkeyTriggered) when it matches. 'ctrl' also matches Cmd/Meta, so the same spec works on both Windows/Linux and macOS.
