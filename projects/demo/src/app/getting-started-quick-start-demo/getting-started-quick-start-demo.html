Common Issues

Styles not loading?

Make sure you've imported 'nexium-ui/styles.css' in your main.ts or global styles file.

Component not recognized?

Ensure the component is imported in your component's imports array (standalone mode).

TypeScript errors?

Run 'npm install' to ensure all dependencies are properly installed.
