Typography

{{ commonService.appName }} ships a single font stack ($font-family: 'Arial', sans-serif) and a small set of size, weight and line-height tokens that every component reads from, so type stays consistent without needing a design system on top.

Type Scale

Body text sizes, from $font-size-xs to $font-size-3xl.

}

Headings

Heading sizes are defined in rem so they scale with the user's root font size.

@for (h of headings; track h.name) {
Aa {{ h.name }} {{ h.value }}
}

Font Weights

Five weights cover everything from muted secondary text to emphasized headings.

@for (w of weights; track w.name) {

}

Line Height

Body copy uses $line-height: 1.5 for comfortable reading; tighten it for headings and dense UI where you don't need the extra breathing room.
