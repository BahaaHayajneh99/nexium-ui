RTL Support

Components avoid hard-coding left/right where a logical property will do, so setting dir="rtl" on a container mirrors padding, borders and text alignment without any extra configuration.

Setting Direction App-Wide

For a fully RTL application, set dir="rtl" on <html> or <body> once - there's no per-component RTL flag to remember.
