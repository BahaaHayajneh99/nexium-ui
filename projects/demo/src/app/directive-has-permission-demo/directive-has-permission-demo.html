Has Permission

A structural directive that renders its content only when a permission is granted. A permission can be a numeric role/code (a TS enum, matching systems that model roles as numbers like Admin=1, Account=2, Employee=3) or a string permission key like 'VW_AUDT' - mix both freely, including within the same array. What "granted" means is entirely up to your app, via an injectable NxPermissionChecker.
