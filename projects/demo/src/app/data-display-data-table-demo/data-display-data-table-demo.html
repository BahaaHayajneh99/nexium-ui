Data Table

Semantic table component for displaying structured data in rows and columns

Overview

The Data Table component provides a clean, semantic way to display structured tabular data. It's perfect for displaying lists of records, comparisons, and any data that benefits from a grid layout. It supports striped rows, hover effects, sorting, and responsive design.
