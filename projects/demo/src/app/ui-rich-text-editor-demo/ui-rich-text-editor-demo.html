Rich Text Editor

A hand-rolled WYSIWYG editor built on contenteditable - covers bold, italic, underline, strikethrough, headings, quotes, lists, links, undo/redo, slash commands, @-mentions, an emoji picker, tables, image upload (picker or drag-drop), code blocks, live markdown shortcuts, optional autosave, and a word/character count. It's not a structured-document editor with a custom schema or real-time collaborative editing; for that, reach for a dedicated library.
