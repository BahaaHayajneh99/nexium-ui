Pipes

A small set of standalone pipes for formatting jobs that come up constantly in real apps - dates, long text, and byte counts - without pulling in a date library or hand-rolling a helper each time.

Token
Means
yyyy
4-digit year
MM
2-digit month (01-12)
dd
2-digit day (01-31)
HH
2-digit hour, 24h (00-23)
mm
2-digit minute (00-59)
ss
2-digit second (00-59)

Same Date object (right now), three different format strings:

Template
Result
{{ '{{ now | nxDateFormat }}' }} (no argument = default)
{{ now | nxDateFormat }}
{{ "{{ now | nxDateFormat:'dd/MM/yyyy' }}" }}
{{ now | nxDateFormat:'dd/MM/yyyy' }}
{{ "{{ now | nxDateFormat:'yyyy-MM-dd HH:mm:ss' }}" }}
{{ now | nxDateFormat:'yyyy-MM-dd HH:mm:ss' }}
