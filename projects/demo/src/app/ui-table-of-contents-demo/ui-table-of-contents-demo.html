Table of Contents

A scroll-spy table of contents. It renders a nested, indented list of links for headings, then watches the real DOM elements elsewhere on the page that share those ids with a native IntersectionObserver, highlighting whichever heading is currently most visible.

Introduction

NexiumUI is a standalone-component library for Angular. Every component ships with no NgModule dependency - just import the class you need and drop its selector into a template.

This page doubles as both documentation and a live demo of the scroll-spy behavior that nx-table-of-contents provides.

Getting started

Most teams are up and running within a few minutes of installing the package. The steps below cover the two things you need before using any component.

Installation

Install the package from npm, then import whichever components you need directly into your standalone component's imports array. There is no root module registration step.

Configuration

Most components work out of the box with sensible defaults. Design tokens (colors, radii, spacing) are exposed as CSS custom properties so you can retheme the whole library from one place.

Core concepts

A handful of ideas recur across the library: standalone components, signal-backed inputs where reactivity matters, and a shared set of CSS variables for theming.

Components

Components are grouped by category - forms, navigation, feedback, data display, and interaction - and each is independently importable, so your bundle only includes what you actually use.

Theming

Override the shell's CSS custom properties at any ancestor element to retheme everything beneath it, including dark mode, without touching component internals.

Advanced usage

Beyond the basics, most components expose template-based extension points (custom templates, content projection) for cases the built-in rendering doesn't cover.

FAQ
