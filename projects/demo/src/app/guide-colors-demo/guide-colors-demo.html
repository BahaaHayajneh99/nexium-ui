Colors

Every color in {{ commonService.appName }} starts life as a SCSS variable in variables.scss and is mirrored as a CSS custom property in styles.scss, so the same palette is available at build time and at runtime.

Brand

The primary brand color and its light/dark variants, used for links, focus states and primary actions.

@for (c of brand; track c.name) {
{{ c.name }}
{{ c.hex }}
}

Status Colors

Semantic colors used consistently across alerts, badges, buttons and form validation states.

@for (c of status; track c.name) {
{{ c.name }}
{{ c.hex }}
}

Neutral Scale

A 10-step gray scale ($gray-50 through $gray-900) used for text, borders and surfaces.

@for (c of grays; track c.name) {
{{ c.name }}
{{ c.hex }}
}

Using Color Tokens

Reach for the SCSS variable inside a component's own stylesheet, and the CSS custom property anywhere else - inline styles, dynamically generated styles, or a stylesheet that doesn't import variables.scss.
