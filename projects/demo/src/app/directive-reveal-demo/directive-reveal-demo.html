Reveal

Applies a reveal animation (fade-in + slight translate by default) to the host element the moment it enters the viewport, via a native IntersectionObserver under the hood (reusing NxInView internally). By default it only animates the first time the element becomes visible; set nxRevealOnce="false" to replay it every time the element scrolls back into view.
