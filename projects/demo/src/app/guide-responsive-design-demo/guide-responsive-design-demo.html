Responsive Design

{{ commonService.appName }} doesn't ship a grid system - components are built to sit inside whatever layout you already have, using relative units (%, rem, flex) so they resize naturally with their container.

Flexible Components

Layout components like nx-card, nx-tabs and nx-accordion default to width: 100% of their parent, so reflow across breakpoints is handled by your grid/flex container rather than the component itself.

Testing Across Sizes

Use the browser's device toolbar (or resize the window) while the dark/light toggle in the top nav is on - most layout regressions show up as soon as a sidebar or table runs out of horizontal room.
